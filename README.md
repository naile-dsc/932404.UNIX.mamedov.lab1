# Лабораторная работа №1: Скрипт сборки

Реализация скрипта автоматической сборки на POSIX Shell в соответствии с требованиями курса «Операционные системы UNIX».

## Описание

Скрипт build.sh выполняет автоматическую компиляцию программ на языках C и C++ во временном каталоге с контролем ошибок и очисткой ресурсов.

### Реализованный функционал
- Поиск директивы: парсинг строки // Output: <имя_файла> с помощью утилиты sed и проверка корректности целевого имени (запрет путей, каталогов . и ..).
- Изолированная сборка: создание временного каталога через mktemp -d и компиляция внутри него без засорения рабочей директории.
- Гарантированная очистка: перехват сигналов завершения (HUP, INT, QUIT, PIPE, TERM) и нормального выхода (0) через trap с обязательным удалением временной директории.
- Информативные коды ошибок: скрипт возвращает дифференцированные коды завершения для каждого типа сбоя (отсутствие аргументов, синтаксические ошибки компилятора, проблемы с файловой системой).
- Флаги компиляции: использование строгих флагов предупреждений и оптимизации (-Wall -Wextra -pedantic -O2).
- Перенос результата: доставка готового исполняемого файла в директорию к исходному коду.
